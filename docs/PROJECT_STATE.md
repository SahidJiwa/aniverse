# AniVerse

## Status Sekarang

Current home screen masih menggunakan section architecture:

- Hero
- Anime World
- Friends Activity
- Community
- Daily Missions
- Collection

## Goal

Transform home screen into game-style lobby.

Inspired by:
- Wuthering Waves
- Honkai Star Rail
- Zenless Zone Zero

## Principles

- No dashboard feeling
- No section stacking
- Protagonist first
- World second
- Actions third
- Community removed from Home
